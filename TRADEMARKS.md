# Trademarks

The names **BYO Stuff**, **BYO Workouts**, **BYO Recipes**, **BYO Macros**, and the **"Works with BYO"** mark identify the official apps and compatible software from this project. The code is licensed under Apache 2.0 (see `LICENSE`), which does not grant any right to use these names.

## What this means

- You can fork, modify, and redistribute the code, including free or ad-supported versions, under any name that isn't one of the names above.
- The names and the "Works with BYO" mark are reserved for software that supports free, complete data export in the documented open format, and can import it.

## Status

The full policy and the "Works with BYO" checklist are not written yet. They will live in the shared `byo-shared` repo, and this file will then point there. Until then, treat the names as reserved and ask before using them.

Name availability checks (App Store Connect, GitHub org, npm scope, trademark search) are still open. See `DECISIONS.md`.
